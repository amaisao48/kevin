A hook. This tells KEVIN to run a check before the AI sends, refunds or deletes anything.

{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "send_email|send_text|refund|delete_file",
        "hooks": [
          { "type": "command", "command": "python hooks/locks.py" }
        ]
      }
    ]
  }
}

The lock itself. Plain code. When it exits with code 2, the action stops and the AI gets told why.

"""Runs before the AI acts. Exit code 2 stops the action."""
import json, sys
from approvals import approved

call = json.load(sys.stdin)
tool = call["tool_name"]

if tool in ("refund", "delete_file"):
    print("Money moves and deletions are locked.", file=sys.stderr)
    sys.exit(2)

if tool.startswith("send_") and not approved(call):
    print("Held: customer messages wait for Mike's yes.", file=sys.stderr)
    sys.exit(2)

Can it trade for me?

Can it build my website?
